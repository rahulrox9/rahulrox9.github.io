Scientific Software & Machine Learning Ecosystems

  • MAPClean: A modular MATLAB pipeline employing parallelised computing and adaptive clustering algorithms for the automated pixel level restoration of large scale multidimensional spatial (EBSD) datasets. DOI: 10.5281/zenodo.18052287
  • GRaMC: A heuristic microstructural reconstruction framework featuring automated crystallographic twin merging and dynamic population filtering to extract robust quantitative datasets. DOI: 10.5281/zenodo.18107589
  • GRaFT: A dual environment analytical ecosystem bridging MATLAB and Python to automate the extraction, statistical visualisation and cross sample synthesis of multidimensional textural data. DOI: 10.5281/zenodo.18107626
  • LaTeCT: An end to end open source Python machine learning pipeline encompassing automated data preprocessing, unsupervised clustering and optimised Random Forest classification to derive predictive models from complex geochemical datasets.
  • DenCalc: A Python based thermodynamic modelling utility utilising pandas and NumPy to compute complex phase specific and bulk densities by integrating pressure, temperature and multicomponent geochemical datasets. DOI: 10.5281/zenodo.16943747
  • MOSAIC (In Development): A comprehensive open source statistical framework for the multivariate analysis of compositional datasets. It integrates unsupervised machine learning (PCA, k means), robust distributional comparisons (Wasserstein distances, bootstrap resampling) and multidimensional variance metrics (Mahalanobis distances) to quantify latent population structures and complex chemical heterogeneity.
