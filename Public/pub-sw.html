Scientific Software & Machine Learning Ecosystems

MAPClean (2025)
Subbaraman, R. (2025b). MAPClean: Microstructurally Adaptive Pixel Level Cleaning. A modular MATLAB pipeline employing parallelised computing and adaptive clustering algorithms for the automated pixel level restoration of large scale multidimensional spatial (EBSD) datasets. DOI: 10.5281/zenodo.18052287
GRaMC (2025)
Subbaraman, R. (2025c). GRaMC: Grain Reconstruction and Multi stage Cleaning. A heuristic microstructural reconstruction framework featuring automated crystallographic twin merging and dynamic population filtering to extract robust quantitative datasets. DOI: 10.5281/zenodo.18107589
GRaFT (2025)
Subbaraman, R. (2025d). GRaFT: Grain Resolved analysis of Fabric and Texture. A dual environment analytical ecosystem bridging MATLAB and Python to automate the extraction, statistical visualisation and cross sample synthesis of multidimensional textural data. DOI: 10.5281/zenodo.18107626
DenCalc (2025)
Subbaraman, R. (2025a). DenCalc: Density Calculator. A Python based thermodynamic modelling utility utilising pandas and NumPy to compute complex phase specific and bulk densities of rocks and their carrier melts by integrating pressure, temperature and multicomponent geochemical datasets. DOI: 10.5281/zenodo.16943747
LaTeCT
LaTeCT: An end to end open source Python machine learning pipeline encompassing automated data preprocessing, unsupervised clustering and optimised Random Forest classification to derive predictive models from complex geochemical datasets.
MOSAIC (In Dev)
MOSAIC: A comprehensive open source statistical framework for the multivariate analysis of compositional datasets. Integrates unsupervised machine learning (PCA, k means), robust distributional comparisons (Wasserstein distances, bootstrap resampling) and multidimensional variance metrics (Mahalanobis distances) to quantify latent population structures and complex chemical heterogeneity.
